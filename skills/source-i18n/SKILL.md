# source-i18n

source-i18n removes translation keys: the source text itself is the key. `t('Save project')` generates a catalog entry `"Save project": "保存项目"`. Do not invent identifiers such as `save_project`.

Use this skill when the project depends on `source-i18n`, or when the user asks to add translations, review missing strings, fix placeholders, configure providers, or set up the CI gate.

## Ground rules

1. **Never introduce a key layer.** Write the real user-facing string inside `t()`.
2. **Only literals can be extracted.** `t(label)`, string concatenation, and `` t(`Exported ${count} files`) `` cannot be translated. Rewrite them as:
   ```ts
   t('Exported {count} files', { count })
   ```
3. **Preserve placeholders exactly.** `{name}`, `{count}`, `{count, number}` must survive translation. Do not rename or remove them.
4. **Use context for ambiguous words.** `t('Open', { context: 'verb' })` and `t('Open', { context: 'state' })` become separate catalog entries.
5. **Do not translate backend errors.** Return error codes from the server and map them in the UI.
6. **Human edits win.** A translation edited by hand is fingerprinted; `sync --force` will not overwrite it.
7. **Never commit secrets.** Provider keys belong in environment variables (`OPENAI_API_KEY`, `DEEPL_API_KEY`, ...).
8. **Dev auto-translate is opt-in.** `dev.autoTranslate` defaults to `false`; enabling it sends source text to the configured provider. Do not enable it on a codebase with sensitive copy without asking.

## Workflow

1. Read `source-i18n.config.mjs` (or `.ts` / `.json`) and find `source`, `locales`, `provider`, `catalogs`, `extract.exclude`.
2. Add or change strings in source files using `t('...')`.
3. Run the read-only checks:
   ```bash
   npx source-i18n extract
   npx source-i18n check --strict
   ```
4. If strings are missing, propose a sync. **Ask before writing**, because sync calls a paid provider:
   ```bash
   npx source-i18n sync --dry-run   # report only
   npx source-i18n sync             # writes catalogs, calls provider
   ```
5. Review the diff in `i18n/locales/*.json`. Only catalogs should change; source edits and catalog writes should be separate concerns.
6. Re-run `check --strict` and report the result.

Never run `sync` with a provider unless the user approved the cost. Never run `sync --prune --prune-manual` without explicit confirmation: it deletes hand-added entries.

## Commands

| Command | Purpose |
|---|---|
| `npx source-i18n init` | Create config and `i18n/locales/` |
| `npx source-i18n extract` | List strings and dynamic calls; no writes |
| `npx source-i18n sync` | Extract and translate missing strings |
| `npx source-i18n sync --dry-run` | Report what would be translated |
| `npx source-i18n sync --force` | Retranslate untouched machine output |
| `npx source-i18n check --strict` | CI gate: missing, invalid, unused, dynamic |
| `npx source-i18n format --check` | Verify catalog normalization |

See `references/commands.md` for every flag and exit code.

## Catalogs

```json
{
  "locale": "en-US",
  "sourceLocale": "zh-CN",
  "messages": {
    "保存项目": "Save project",
    "打开@@verb": "Open",
    "已导出 {count} 个文件": "{count, plural, one {Exported # file} other {Exported # files}}"
  }
}
```

- `@@` separates source text from a context.
- `{count, plural, ...}` is only generated by the library, never by the model.
- `*.meta.json` stores machine fingerprints; do not edit it by hand.

## Common failures

| Symptom | Cause | Fix |
|---|---|---|
| Page shows source text, no warning | File not processed by the plugin | Add the plugin to both dev and build configs |
| `dynamic t() call` | Variable or interpolated template | Literal + placeholder |
| Missing translation after editing copy | Source text is the key, so new text is a new entry | Run sync; old entry becomes `unused` |
| Placeholder validation fails | Hand edit removed `{name}` | Restore placeholders, run `check` |
| `no config file found` | Wrong cwd | Run at project root or pass `--root` |
| 401 / 403 | Missing or wrong key | Set env var, restart dev server |
